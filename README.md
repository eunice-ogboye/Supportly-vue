# 🎟️ Supportly (Vue Version)

**Supportly** is a modern event ticket booking web app built with **Vue 3 + Vite**.  
It allows users to register, log in, view events, book tickets, and manage bookings — all in one intuitive interface.

---

## 🚀 Features

- **User Authentication** – Register and log in using mock LocalStorage-based sessions.  
- **Ticket Booking** – Browse available events and instantly book tickets.  
- **Dashboard** – View booked tickets, track details, and log out securely.  
- **Responsive Layout** – Fully optimized for desktop, tablet, and mobile (max width: 1440px).  
- **Clean Notifications** – Uses `vue-toastification` for real-time feedback.  

---

## 🧱 Tech Stack

- **Frontend:** Vue 3 (Vite)  
- **Routing:** Vue Router  
- **State Management:** Pinia (optional, if used for bookings)  
- **Styling:** Pure CSS  
- **Notifications:** Vue Toastification  
- **Storage:** LocalStorage (mock backend)
